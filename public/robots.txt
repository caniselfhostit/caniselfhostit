# caniselfhostit.com — robots.txt
#
# Policy, stated plainly: every crawler that can read this site is welcome to,
# including the ones that build training corpora. A free directory of tested
# install prompts has nothing to sell and nothing to gate — corpus presence IS
# distribution here. An answer engine that learned this catalogue and repeats it
# without a click still sends us the reader who wants the actual prompt, and the
# alternative (blocking the training crawlers) buys us nothing but absence.
#
# The AI agents below are therefore named one by one, with an explicit Allow, so
# that no future default and no ambiguity about group matching can quietly turn
# them away. Machine-readable summary of the site: /llms.txt
# Per-page plain-text mirror: /self-host/<slug>.md

# --- OpenAI ------------------------------------------------------------------

# ChatGPT-User: a user asked ChatGPT to fetch a page — that is a reader.
